СТИЛЬ И ВИЗУАЛ

Сделай дизайн:
— премиальный
— атмосферный
— современный
— с глубиной
— с аккуратными эффектами
— с сильным первым экраном
— с ощущением creative tech / web fashion / AI aesthetic

Визуальный стиль:
— темная или светлая premium-стилистика на выбор, но итог должен выглядеть дорого
— можно использовать мягкие градиенты, blur, glow, glassmorphism, легкие свечения, layered UI
— типографика должна быть выразительной
— крупные заголовки
— хороший воздух между блоками
— карточки, кнопки и секции должны выглядеть чисто и эстетично

Важно:
— сайт должен быть визуально цельным
— все секции должны быть в одном стиле

— дизайн должен вызывать ощущение: “это хочется листать и переслать”
